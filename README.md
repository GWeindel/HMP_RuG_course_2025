# ML4CCS lecture
Supporting files and slides for the class ML4CCS given at the university of Groningen (2025-12-15)

Installation: In order to follow the second part you need to have HMP installed so please follow the instructions here: https://hmp.readthedocs.io/en/latest/installation.html
I recommend you clone the entire repository (https://github.com/GWeindel/hmp) using `git`. If you're not familiar with git you can just use the `pip install` command in the link above.
